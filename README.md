# NEMAX Messenger

Учебный локальный мессенджер на Go с TCP-клиентом, браузерным интерфейсом, авторизацией и обменом личными сообщениями в реальном времени. Данные пользователей, сессий и сообщений хранятся в памяти приложения.

## Стек

- Go 1.23+, `net`, `net/http`, горутины, `sync`
- TCP-сокеты для консольного клиента и сервера
- HTTP API, HTML, CSS, JavaScript для web-интерфейса
- WebSocket (`gorilla/websocket`) для уведомлений о новых сообщениях
- `bcrypt` для хранения хешей паролей

## Архитектура

Клиент-серверное приложение с несколькими транспортами и in-memory хранилищами:

- `main.go`, `client.go` - запуск сервера или TCP-клиента из командной строки
- `internal/messenger` - сборка приложения и одновременный запуск TCP- и HTTP-серверов
- `internal/tcpserver` - текстовый TCP-протокол: вход, список пользователей, отправка и чтение сообщений
- `internal/httpapi` - web-страницы и HTTP API для регистрации, входа, диалогов и отправки сообщений
- `internal/ws` - WebSocket hub для доставки новых сообщений открытым web-клиентам
- `internal/users`, `internal/sessions`, `internal/messages` - хранение данных в памяти процесса
- `internal/ratelimit` - ограничение попыток входа и временная блокировка

База данных не используется: после перезапуска сервера зарегистрированные пользователи, сессии и история сообщений сбрасываются.

## Как запустить

Нужен Go 1.23+.

Запустить сервер:

```bash
go run . -mode=server -addr=:9000
```

После запуска web-интерфейс будет доступен по адресу:

```text
http://localhost:8080
```

Для проверки уже созданы учебные аккаунты:

```text
admin1 / admin1
admin2 / admin2
```

В другом терминале можно подключить консольный TCP-клиент:

```bash
go run . -mode=client -addr=127.0.0.1:9000
```

Пример TCP-команд:

```text
LOGIN admin1 admin1
USERS
SEND admin2 Привет!
INBOX
LOGOUT
QUIT
```
